# Racing Simulator 3D

Prototype de jeu de conduite 3D en navigateur, construit avec Three.js.

## Lancer le jeu
Le projet fonctionne sans compilation : ouvrez `index.html` avec un serveur web local, ou activez GitHub Pages dans **Settings → Pages** en choisissant la branche `main` et le dossier `/ (root)`.

## Commandes
- **Z / Flèche haut** : accélérer
- **S / Flèche bas** : freiner
- **Q / D** ou **flèches gauche/droite** : tourner
- **C** : basculer entre caméra extérieure et cockpit
- **Recommencer** : remettre la voiture au départ

Les commandes tactiles apparaissent sur les petits écrans.

## État du prototype
- Scène 3D temps réel, éclairage, ombres et circuit ovale
- Voiture 3D provisoire et conduite arcade de test
- Caméra extérieure suiveuse et vue cockpit
- HUD vitesse/rapport et commandes mobiles
